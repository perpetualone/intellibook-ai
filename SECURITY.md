# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Email **support@intellibookai.com** with the subject "Security report" and include:

- what you found and where (URL, endpoint or file),
- steps to reproduce,
- the impact you expect.

We aim to acknowledge reports within 3 business days and will keep you updated until the issue is resolved.

## Scope

- The code in this repository (CLI, WordPress plugin).
- The public API and MCP server at `https://www.intellibookai.com`.

Please do not test against other customers' data, send high-volume traffic, or attempt social engineering.

## Secrets

No API keys or credentials belong in this repository. If you spot one, report it as above.
